用語集

本書で使う主な用語を、五十音順（英字で始まる用語は末尾）にまとめる。

アムダールの法則

プログラムの一部だけを並列化したときの、全体の速度向上率の上限を表す法則。並列化できない部分の割合が大きいほど、コアを増やしても速くならない。詳しくは 第 2 章 基本概念 を参照。

イベントループ

asyncio の中心となる仕組み。実行できる状態のタスクを 1 つずつ実行し、await で中断したタスクは I/O の準備ができるまで待たせる。詳しくは 第 8 章 asyncio による非同期処理（基礎） を参照。

競合状態

複数のスレッドが同じデータを同時に読み書きすることで、実行のタイミングによって結果が変わってしまう状態。race condition。詳しくは 第 5 章 スレッドによる並行処理 を参照。

協調的マルチタスク

タスクが自分から制御を譲ることで切り替わる方式。asyncio では await の箇所でだけタスクが切り替わる。

コルーチン

async def で定義した関数（コルーチン関数）を呼び出したときに返されるオブジェクト。await されたり、タスクとして登録されたりしたときに実行される。

サブインタプリタ

1 つのプロセスの中に作られる、互いに独立した Python のインタプリタ。Python 3.12 以降ではそれぞれが独立した GIL を持つ。詳しくは 第 10 章 GIL を超える新しい選択肢 を参照。

スレッド

プロセスの中で動く実行の単位。同じプロセスのスレッドはメモリを共有する。

スレッドセーフ

複数のスレッドから同時に使っても、正しく動作すること。

タスク

asyncio で、イベントループに登録されて並行に実行されるコルーチン。asyncio.Task クラスのオブジェクト。

逐次処理

複数の処理を 1 つずつ順に実行すること。

デッドロック

複数のスレッドが互いに相手の持つロックの解放を待ち、どのスレッドも先に進めなくなる状態。詳しくは 第 5 章 スレッドによる並行処理 を参照。

排他制御

ある範囲の処理を、同時に 1 つのスレッドだけが実行できるようにする制御。ロックなどを使う。

非同期処理

処理の完了を待たずに先に進み、完了したことを後から受け取る方式。本書では、asyncio の async / await 構文による並行処理を指す。

ブロッキング

処理が完了するまで、呼び出したスレッドが止まること。

プロセス

OS が管理するプログラムの実行単位。プロセスごとに独立したメモリ空間を持つ。

並行処理

複数の処理を、それぞれが終わるのを待たずに切り替えながら進めること。同時に実行されているとは限らない。

並列処理

複数の処理を、複数の CPU コアで物理的に同時に実行すること。

ロック

排他制御のための仕組み。ロックを獲得したスレッドだけが、保護された範囲を実行できる。Python では threading.Lock などを使う。

CPU バウンド

処理時間の大部分を CPU による計算が占める処理。並列処理によって複数のコアで計算すると速くなる。詳しくは 第 2 章 基本概念 を参照。

CPython

C 言語で実装された Python の公式の処理系。python.org で配布されている Python は CPython である。

free-threaded ビルド

GIL を無効にした CPython。Python 3.13 で実験的に提供され、Python 3.14 で正式にサポートされた。詳しくは 第 10 章 GIL を超える新しい選択肢 を参照。

Future

実行を依頼したタスクの将来の結果を表すオブジェクト。concurrent.futures.Future と asyncio.Future がある。

GIL

Global Interpreter Lock の略。CPython で、Python のバイトコードを実行できるスレッドを、ある時点で 1 つに制限するロック。詳しくは 第 3 章 CPython の実行モデルと GIL を参照。

I/O バウンド

処理時間の大部分を、ネットワークやファイルなどの入出力の完了を待つ時間が占める処理。並行処理によって待ち時間を重ねると速くなる。詳しくは 第 2 章 基本概念 を参照。

pickle

Python のオブジェクトをバイト列に変換（シリアライズ）する標準ライブラリのモジュール。プロセス間でのデータの受け渡しに使われる。
